Step 0 — Setup (one time, ~10 min)

  1. Clone the bundle and enter it: 
    git clone <your-repo-url> kdd-tutorial
cd kdd-tutorial/experiment/github_submission
  2. Install the package (offline-only deps; no GPU/heavy ML libs needed for Phases 1–2): 
    pip install numpy matplotlib pyyaml
python -m compileall -q source # sanity check
  3. For Phase 1's LLM techniques, export the free OpenAI-compatible gateway: 
    export OPENAI_API_KEY=-<your-key>
export OPENAI_BASE_URL=https://api.openai.com/v1
  4. For Phase 3, set up Modal (L4 access, no H100/payment needed): 
    pip install modal && modal setup

Phase 1 Agent Memory Techniques (60 min)

Goal: see how every memory pattern stores and retrieves. All 30 techniques are surveyed by family; you run a curated subset hands-on.

Open: tutorial/phase1_memory_architectures/notebook.ipynb 
jupyter notebook tutorial/phase1_memory_architectures/notebook.ipynb
Run top-to-bottom. The consolidated demo contrasts the four architectures on one conversation: 
verbatim size=4 top="Alice: I work as a data scientist in Berlin"
extracted_facts size=4 top="Alice: the user work as a data scientist ..."
episodic size=2 top="Bob: OOM at batch 256; fixed with batch 64 ..."
hybrid size=6 top="Alice: I work as a data scientist in Berlin"

Each technique notebook (01–08) is self-contained and picks up the gateway from the interactive LLM-setup cell at the top (or the env vars above) — no external notebooks required.

Time: ~5 s for the core demo; ~10 min one-time deps if running the LLM techniques.

Phase 2 Public datasets (60 min, offline, no key)

Goal: diagnose retrieval vs utilization failures, then benchmark the providers on real data (LoCoMo · LongMemEval · MemoryArena).

Exercise 1 — memory failure diagnosis

cd source
python -m diagnostic_framework diagnose \
 --strategies verbatim,extracted_facts,episodic,hybrid \
 --probes relevance,utilization,failure --top_k 5 --max-questions 20

Read the table: is util ever different from hit? (It should be — that's the retrieval-vs-utilization gap.) Time: ~1.3 s.

Exercise 2 — benchmarking memory systems

python -m benchmark_cli compare \
 --providers verbatim,extracted_facts,episodic,hybrid \
 --sample_size 20 --benchmark memoryarena

Compare accuracy/latency/cost across providers. Time: ~4.4 s.

Or run it as a notebook: tutorial/phase2_public_datasets/notebook.ipynb.

Phase 3 Autoresearch, group-split (60 min, Modal L4)

Goal: the autonomous-research case study. Split into groups so each slice fits one L4 (deeper models use smaller batch — this avoids the depth≥12 OOM that breaks a single full run).

Groupconfigs (depth, batch)
A(4,32), (6,32)
B(8,32), (10,32)
C(12,16), (14,16)
D(16,16), (18,16)
Each group runs its slice (~14.5 min on an L4, measured): 
cd .. # back to github_submission/
modal run scripts/build_autoresearch_trace.py --group A # A | B | C | D
Results stream to source/data/topics/autoresearch/leaderboard/<group>.json.

Aggregate the combined depth-4→18 sweep + the keep/revise/discard memory-debug loop in tutorial/phase3_autoresearch/notebook.ipynb (reads all leaderboard/*.json).

Troubleshooting

No module named diagnostic_framework — run Phase 2 commands from the source/ directory (or pip install -e source).

Could not locate source/run.py — notebook path cell: run from the repo root, or pip install -e source.

Modal “add a payment method for H100” — you're on H100; Phase 3 uses L4 via build_autoresearch_trace.py (no payment needed).

Phase 1 LLM techniques fail — confirm echo $OPENAI_BASE_URL points at an OpenAI-compatible endpoint.
